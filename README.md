# AutoExpert AI - System Wspomagania Decyzji (TOPSIS)

Projekt inżynierski stanowiący hybrydowy system decyzyjny służący do rekomendacji pojazdów na podstawie algorytmu TOPSIS (Technique for Order of Preference by Similarity to Ideal Solution).

## Architektura i technologie

- **Frontend:** React (Vite) + Tailwind CSS v4
- **Wizualizacja XAI:** Recharts (Wykresy radarowe)
- **Testy:** Vitest + React Testing Library
- **Stan:** LocalStorage (Baza wiedzy z pełnym CRUD)

## Uruchomienie lokalne

1. Instalacja zależności: `npm install`
2. Serwer developerski: `npm run dev`
3. Uruchomienie testów (Unit + UI): `npm run test:run`
