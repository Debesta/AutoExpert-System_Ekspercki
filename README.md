# AutoExpert - System Wspomagania Decyzji (TOPSIS)

Projekt inżynierski stanowiący hybrydowy system decyzyjny służący do rekomendacji pojazdów na podstawie algorytmu TOPSIS (Technique for Order of Preference by Similarity to Ideal Solution).[cite: 1]

## Wersja live (Demo)

🌍 Aplikacja jest dostępna online: [Uruchom AutoExpert](https://autoexpert-systemekspercki.netlify.app)

## Architektura i technologie

- **Frontend:** React (Vite) + Tailwind CSS v4[cite: 1]
- **Wizualizacja XAI:** Recharts (Wykresy radarowe)[cite: 1]
- **Testy:** Vitest + React Testing Library[cite: 1]
- **Stan:** LocalStorage (Baza wiedzy z pełnym CRUD)[cite: 1]

## Uruchomienie lokalne

1. Instalacja zależności: `npm install`[cite: 1]
2. Serwer developerski: `npm run dev`[cite: 1]
3. Uruchomienie testów (Unit + UI): `npm run test:run`[cite: 1]
